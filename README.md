# 지면 · Jimyeon

**블록으로 구성하고, 페이지로 완성하는 문서 에디터.**

지면은 A4·A3 종이 위에 바로 쓰듯이 문서를 만들고, 화면에서 편집한 배치 그대로 PDF로 저장하는 앱입니다. 이력서, 보고서, 기획서, 포트폴리오처럼 페이지 모양이 중요한 문서를 만들 때 좋습니다. 맥과 윈도우에서 무료로 쓸 수 있습니다.

## 내려받기

[![지면 내려받기](https://img.shields.io/badge/%EB%82%B4%EB%A0%A4%EB%B0%9B%EA%B8%B0-%EB%A7%A5%20%C2%B7%20%EC%9C%88%EB%8F%84%EC%9A%B0-2365a8?style=for-the-badge)](https://github.com/vpdls1511/Jimyeon/releases/latest)

위 버튼을 누르면 최신 버전 페이지가 열립니다. 페이지 아래쪽 **Assets** 목록에서 내 컴퓨터에 맞는 파일 하나만 받으면 됩니다.

**어떤 파일을 받으면 되나요?**

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| 맥 · Apple 칩 (M1, M2, M3 등) | `Jimyeon-버전-macOS-arm64.dmg` |
| 맥 · Intel 칩 | `Jimyeon-버전-macOS-x64.dmg` |
| 윈도우 | `Jimyeon-버전-Windows-x64-Setup.exe` |

파일 이름의 '버전' 자리에는 `1.0.1` 같은 숫자가 들어 있습니다. 이름이 `.zip`으로 끝나는 파일은 같은 앱을 압축해 둔 것입니다. 윈도우에서 설치 과정 없이 쓰고 싶을 때 받으세요. `SHA256SUMS.txt`는 [파일 확인용](#내려받은-파일이-진짜인지-확인하고-싶어요)이고, **Source code**는 프로그램 코드라서 받지 않아도 됩니다.

**내 맥이 어느 쪽인가요?** 화면 왼쪽 위 Apple 메뉴에서 **이 Mac에 관하여**를 누르세요. **칩** 항목에 'Apple M1'처럼 Apple로 시작하는 이름이 있으면 Apple 칩입니다. 칩 대신 **프로세서** 항목이 있고 거기에 Intel이 보이면 Intel 칩입니다.

받은 다음에는 [설치하기](#설치하기)를 따라 하세요.

## 주요 기능

**종이 위에서 바로 씁니다.** A4나 A3 용지를 고르면 화면에 실제 종이 크기의 페이지가 나타납니다. 어디서 다음 장으로 넘어가는지 보면서 쓸 수 있습니다. 위·아래·왼쪽·오른쪽 여백과 페이지 번호를 정할 수 있고, 원하는 곳에서 직접 페이지를 나눌 수도 있습니다.

**블록을 쌓듯이 씁니다.** 문단, 제목, 이미지처럼 내용 하나하나가 '블록'입니다. 블록은 끌어서 옮기고, 복제하고, 여러 개를 한꺼번에 고를 수 있습니다. 블록을 2~5열로 나란히 놓을 수 있고, 열 안에 다시 열을 넣을 수도 있습니다. 맞닿은 두 열은 경계를 끌어 너비를 바꿉니다.

**이미지와 미디어를 넣습니다.** 컴퓨터에 있는 이미지를 넣고 크기와 정렬을 바꿀 수 있습니다. 영상, 오디오, 파일도 넣을 수 있고, 웹 주소로 이미지나 영상을 넣거나 다른 웹 페이지를 문서 안에 띄우는 임베드, 링크 카드(북마크)도 만들 수 있습니다.

**문서에 필요한 서식을 갖췄습니다.** 제목, 목록, 표, 코드, 수식, 강조 상자(콜아웃), 접었다 펴는 토글, 탭, 목차를 쓸 수 있습니다. 링크 색상과 구분선의 색상·불투명도도 바꿀 수 있습니다.

**간격을 꼼꼼하게 맞춥니다.** 본문 글자 크기를 정하면 본문 속 제목 크기도 따라서 맞춰지고, 문서 맨 위 제목의 크기는 따로 정합니다. 문서 전체의 줄 간격(행간), 글자 사이 간격(자간), 블록 사이 간격을 정할 수 있고, 블록마다 위아래 여백을 따로 줄 수도 있습니다.

**저장은 알아서, 내보내기는 원하는 대로.** 쓰는 동안 자동으로 저장됩니다. 문서를 파일로 저장해 백업하고 다시 불러올 수 있고, Markdown(다른 프로그램에서도 열리는 간단한 글 형식)으로 내보낼 수도 있습니다. PDF는 화면에 보이는 배치대로 저장됩니다. 다만 PDF에서는 영상·오디오·임베드를 재생할 수 없습니다. 그래서 컴퓨터에서 넣은 영상은 화면에 보이던 장면으로 들어가고, 웹 주소로 넣은 영상과 오디오·임베드는 주소나 파일 이름을 적은 카드로 들어갑니다. 영상이 아직 화면에 나타나기 전이면 컴퓨터에서 넣은 영상도 카드로 들어갑니다.

지면은 혼자 쓰는 문서 앱입니다. 계정, 공유, 댓글, 여럿이 함께 편집하기, 여러 기기 사이의 문서 동기화 기능은 없습니다.

## 설치하기

**처음 열 때 경고 창이 뜹니다. 서명이 없어서 뜨는 경고이고, 바이러스가 있다는 뜻은 아닙니다.**

지면은 Apple의 공증과 윈도우용 코드 서명을 받지 않았습니다. 공증은 Apple이 앱을 만든 사람을 확인하고 악성 코드가 없는지 검사해 주는 절차이고, 코드 서명은 윈도우에 앱을 누가 만들었는지 알려 주는 절차입니다. 이런 확인이 없는 앱은 처음 열 때 운영체제가 한 번 더 묻습니다. 아래 방법은 이 페이지의 [내려받기](#내려받기) 링크에서 받은 파일에만 쓰세요. 화면에 나오는 문구는 운영체제 버전에 따라 조금 다를 수 있습니다.

### 맥

1. 내려받은 `.dmg` 파일을 두 번 클릭합니다.
2. 창이 열리면 **Jimyeon** 아이콘을 옆에 있는 **Applications**(응용 프로그램) 폴더로 끌어다 놓습니다.
3. Finder의 **응용 프로그램** 폴더에서 **Jimyeon**을 두 번 클릭합니다.
4. Apple이 악성 코드가 있는지 확인할 수 없다는 창이 뜨면 **완료**(또는 **확인**)를 눌러 닫습니다. **휴지통으로 이동**은 누르지 마세요.
5. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래로 내립니다. **보안** 항목에서 Jimyeon이 차단되었다는 문구 옆의 **그래도 열기**(macOS 버전에 따라 **열기** 또는 **확인 없이 열기**)를 누릅니다. 이 버튼은 앱을 열려고 한 뒤 1시간쯤만 보입니다. 버튼이 보이지 않으면 3번부터 다시 하세요.
6. 한 번 더 묻는 창에서 **열기**(또는 **그래도 열기**)를 누르고, 맥 로그인 암호를 넣어 확인합니다.

이 과정은 처음 한 번만 하면 됩니다. 다음부터는 두 번 클릭만 하면 열립니다. `.zip` 파일을 받았다면 두 번 클릭해 압축을 풀고, 나온 Jimyeon을 응용 프로그램 폴더로 옮긴 뒤 3번부터 따라 하세요.

<details>
<summary>그래도 열리지 않을 때</summary>

'손상되었기 때문에 열 수 없다'는 창이 뜨거나 위 방법으로도 열리지 않으면 터미널을 써 볼 수 있습니다.

1. **응용 프로그램 → 유틸리티 → 터미널**을 엽니다.
2. 아래 한 줄을 복사해 붙여 넣고 Return 키를 누릅니다.

   ```bash
   xattr -dr com.apple.quarantine /Applications/Jimyeon.app
   ```

3. Jimyeon을 다시 엽니다.

이 명령은 '인터넷에서 받은 파일'이라는 표시만 지웁니다. 공식 다운로드에서 받은 파일에만 쓰세요.

</details>

### 윈도우

1. 파일을 받을 때 브라우저가 경고하면 파일을 남겨 둡니다. 예를 들어 Edge에서 '일반적으로 다운로드되지 않습니다'라는 경고가 뜨면, 내려받기 목록에서 파일 옆 **…** 메뉴를 열고 **유지**를 누릅니다. 한 번 더 물으면 파일을 남기는 쪽을 고릅니다. 문구는 브라우저와 버전마다 다를 수 있습니다.
2. 내려받은 `Setup.exe` 파일을 두 번 클릭합니다.
3. 파란색 **Windows의 PC 보호** 창이 뜨면 **추가 정보**를 누르고, 아래에 나타나는 **실행**을 누릅니다.
4. 설치 프로그램이 누구를 위해 설치할지 물으면, 처음 골라져 있는 그대로 두고 **다음**을 누릅니다. 지금 쓰는 사용자에게만 설치됩니다. **모든 사용자**를 고르면 관리자 확인 창이 뜨는데, 이때는 **예**를 누르면 됩니다. 이 창에 게시자가 '알 수 없음'으로 나오는 것도 서명이 없기 때문입니다. 그다음은 안내에 따라 설치합니다. 설치할 폴더를 바꿀 수도 있습니다.
5. 다 끝나면 바탕 화면이나 시작 메뉴의 **지면**을 눌러 실행합니다.

`.zip` 파일을 받았다면 파일을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 고르고, 나온 폴더에서 **Jimyeon.exe**를 실행하세요. 설치하지 않고 바로 쓸 수 있습니다. 같은 경고 창이 뜨면 3번처럼 하면 됩니다.

<details>
<summary>그래도 열리지 않을 때</summary>

**Windows의 PC 보호** 창 대신 앱을 막았다는 창이 뜨고 **실행** 버튼이 없다면, 윈도우 11의 **스마트 앱 컨트롤**이 켜져 있을 수 있습니다. 이 기능은 서명이 없는 앱을 막고, 앱 하나만 골라 허용할 방법이 없습니다. 자세한 내용은 Microsoft의 [스마트 앱 컨트롤 안내](https://support.microsoft.com/ko-kr/windows/what-is-smart-app-control-285ea03d-fa88-4d56-882e-6698afdb7003)를 보세요.

</details>

## 처음 써 보기

설치를 마쳤다면 1분만 따라 해 보세요.

1. **지면을 엽니다.** 빈 A4 페이지가 보입니다. 맨 위 **제목 없음** 자리에 제목을 쓰고 Enter를 누르면 본문으로 내려갑니다.
2. **`/`로 블록을 넣습니다.** 빈 줄에서 `/`를 누르면 제목, 목록, 표, 이미지처럼 넣을 수 있는 블록 목록이 나옵니다. `/이미지`처럼 이름을 이어서 치면 바로 찾을 수 있습니다.
3. **용지를 고릅니다.** 페이지 위쪽 막대의 **용지**에서 A4나 A3를 고릅니다. 여백과 페이지 번호는 같은 막대의 **페이지 설정**에서 바꿉니다.
4. **PDF로 저장합니다.** 같은 막대 오른쪽의 **PDF 저장**을 누르고 저장할 곳을 고릅니다.
5. **문서 파일로 백업합니다.** 맨 위 오른쪽의 **문서 저장**을 누르고, 형식은 그대로 둔 채 **저장**을 누른 뒤 저장할 곳을 고릅니다. 지면 문서(`.jimyeon`) 파일이 만들어집니다. 나중에 문서 메뉴(**…**)의 **가져오기**로 다시 열 수 있습니다.

여러 기능을 담은 [시작 문서](examples/welcome.jimyeon)도 있습니다. 링크를 열고 오른쪽 위의 내려받기 버튼(Download raw file)으로 받은 뒤 **가져오기**로 열어 보세요. 가져온 문서는 지금 화면의 문서 대신 열리니, 쓰던 문서가 있다면 먼저 문서 파일로 저장해 두세요.

## 사용법

단축키의 `⌘/Ctrl`은 맥에서는 ⌘(Command) 키, 윈도우에서는 Ctrl 키를 뜻합니다. `⌘/Ctrl` + `P`는 그 키를 누른 채 P를 누른다는 뜻입니다.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 블록 넣기 | 빈 줄에서 `/`를 치고 고르기 |
| 블록 옮기기 | 블록 왼쪽에 마우스를 올리면 나오는 손잡이(⋮⋮)를 끌기 |
| 블록 메뉴 (종류 바꾸기(**전환**)·색상·복제·삭제) | 손잡이를 누르거나 `⌘/Ctrl` + `/`(슬래시). 메뉴 바깥을 누르거나 Esc로 닫기 |
| 블록 나란히 놓기 | 블록 메뉴 → **가로 배치** → 2~5열 |
| 목록 만들기 | 줄 맨 앞에 `- `, `1. `, `[]` 입력 |
| 페이지 나누기 | `/페이지 나누기` |
| PDF로 저장 | **PDF 저장** 또는 `⌘/Ctrl` + `P` |
| 문서 파일로 저장 | **문서 저장** 또는 `⌘/Ctrl` + `S` |
| 찾기·바꾸기, 되돌리기 | `⌘/Ctrl` + `F`, `⌘/Ctrl` + `Z` |

| 블록 아래 여백 2pt 늘리기 | `⌘+⌥+↓` | `Ctrl+Alt+↓` |
| 블록 위 여백 2pt 줄이기 | `⌘+⌥+Shift+↑` | `Ctrl+Alt+Shift+↑` |
| 블록 아래 여백 2pt 줄이기 | `⌘+⌥+Shift+↓` | `Ctrl+Alt+Shift+↓` |

위쪽 막대의 **블록 여백**에서 위·아래 값을 직접 넣거나 **문서 기본값 따르기**로 되돌릴 수 있습니다. 블록 하나의 여백은 0~96pt까지 줄 수 있습니다. 페이지의 위·아래·왼쪽·오른쪽 여백(mm)과 문서 전체의 행간·자간·기본 블록 간격은 **페이지 설정**에서 바꿉니다.

</details>

## 내 문서는 어디에 저장되나요?

지면에는 계정도 서버도 없습니다. 문서는 지금 쓰는 이 컴퓨터에만 저장되고, 지면이 문서를 다른 곳으로 보내지 않습니다. 다만 웹 주소로 넣은 이미지·영상·오디오·임베드가 있으면, 그 내용을 보여 주려고 해당 주소에 접속합니다. 북마크(링크 카드)는 주소에 접속하지 않고, 누르면 브라우저로 열립니다.

**자동 저장.** 쓰는 동안 저절로 저장됩니다. 맨 위에 '저장됨'이 보이면 저장이 끝난 것입니다. 자동 저장 파일은 아래 폴더에 있습니다.

| 운영체제 | 자동 저장 폴더 |
| --- | --- |
| 맥 | `~/Library/Application Support/ResumeEditor/` |
| 윈도우 | `%APPDATA%\ResumeEditor\` |

맥은 Finder에서 Shift+⌘+G를, 윈도우는 Windows 키+R을 누른 뒤 위 주소를 붙여 넣으면 폴더가 열립니다. 폴더 이름이 `ResumeEditor`인 것은 지면의 예전 이름 때문입니다. 예전 버전에서 쓰던 문서를 그대로 이어 쓸 수 있도록 이름을 바꾸지 않았습니다. 이 폴더에는 지금 문서(`document.json`)와 바로 전 저장본(`document.previous.json`)이 들어 있습니다. 이 파일을 읽지 못했다는 안내가 뜨면 [자주 묻는 질문](#자동-저장된-문서를-열지-못했다는-안내가-떠요)을 보세요.

**문서는 한 번에 하나.** 지면은 한 번에 문서 하나를 엽니다. 문서 메뉴(**…**)의 **새 문서**로 새 문서를 만들거나 다른 문서를 **가져오면** 화면의 문서가 바뀝니다. 바뀌기 직전의 내용은 문서 메뉴(**…**)의 **저장 기록**에 남고, 쓰는 동안에도 일정한 간격으로 기록이 쌓입니다. 저장 기록은 최근 20개까지만 남으니, 오래 둘 문서는 꼭 문서 파일로 저장해 두세요.

**백업.** **문서 저장**(`⌘/Ctrl` + `S`)을 누르고 형식을 고릅니다.

| 형식 | 이럴 때 고르세요 |
| --- | --- |
| 지면 문서 (`.jimyeon`) | 백업할 때 가장 좋습니다. 블록, 열, 이미지, 페이지 설정을 모두 그대로 담습니다. |
| JSON 문서 (`.json`) | 지면 문서와 같은 내용을 담는 다른 형식입니다. |
| Markdown (`.md`) | 다른 프로그램에서 글을 열어 볼 때 씁니다. 열 배치, 이미지 정렬, 페이지 설정 같은 세부 서식은 남지 않습니다. |

컴퓨터에서 넣은 이미지는 문서 파일 안에 함께 들어갑니다. 그래서 `.jimyeon` 파일 하나만 옮기면 다른 컴퓨터에서도 **가져오기**로 이어서 쓸 수 있습니다.

## 자주 묻는 질문

### 경고 창이 떠요. 열어도 괜찮나요?

서명이 없어서 뜨는 경고입니다. 여는 방법은 [설치하기](#설치하기)에, 받은 파일을 확인하는 방법은 [아래](#내려받은-파일이-진짜인지-확인하고-싶어요)에 있습니다.

### 내 지면 버전은 어떻게 확인하나요?

맥은 지면을 연 상태에서 화면 맨 위 메뉴 막대의 앱 이름 메뉴(Apple 메뉴 바로 오른쪽)를 열고 **지면 정보**를 누르면 버전이 보입니다. 윈도우는 **설정 → 앱 → 설치된 앱**(윈도우 10은 **앱 및 기능**)의 Jimyeon 항목에 버전이 함께 나옵니다. 압축 파일로 쓰고 있다면 받은 파일 이름(예: `Jimyeon-1.0.1-Windows-x64.zip`)의 숫자가 버전입니다.

### 새 버전은 어떻게 받나요? 쓰던 문서는 남아 있나요?

지면은 스스로 업데이트하지 않습니다. [최신 버전 페이지](https://github.com/vpdls1511/Jimyeon/releases/latest)나 위의 버전 표시를 [내 버전](#내-지면-버전은-어떻게-확인하나요)과 비교해 보세요. 새 버전이 있으면 먼저 지면 창을 닫아 앱을 종료합니다. 켜 둔 채로는 새 버전으로 바뀌지 않을 수 있습니다. 그다음 새 파일을 받아 처음과 같은 방법으로 설치하면 됩니다. 맥은 새 Jimyeon을 응용 프로그램 폴더로 옮길 때 **대치**를 누르고, 윈도우는 새 `Setup.exe`를 실행합니다. 압축 파일로 쓰고 있었다면 새 압축 파일을 풀어 그 안의 Jimyeon.exe를 쓰면 됩니다.

문서는 앱과 따로 [자동 저장 폴더](#내-문서는-어디에-저장되나요)에 있어서, 새 버전을 덮어 설치해도 그대로 남습니다. 그래도 업데이트 전에 **문서 저장**으로 백업해 두면 더 안심할 수 있습니다. 새 버전에서 저장한 문서는 이전 버전에서 열리지 않으니, 한 번 새 버전으로 바꾼 뒤에는 이전 버전으로 돌아가지 않는 것이 좋습니다. 새 버전도 처음 열 때 경고 창이 다시 뜰 수 있는데, 같은 방법으로 열면 됩니다.

### 지우고 싶어요

맥은 응용 프로그램 폴더의 Jimyeon을 휴지통으로 옮기면 됩니다. 윈도우는 **설정 → 앱 → 설치된 앱**(윈도우 10은 **앱 및 기능**)에서 Jimyeon을 찾아 **제거**합니다. 압축 파일로 쓰던 경우에는 그 폴더를 지우면 됩니다.

앱을 지워도 문서는 [자동 저장 폴더](#내-문서는-어디에-저장되나요)에 남습니다. 문서까지 모두 지우려면 `ResumeEditor` 폴더도 지우세요. 이 폴더를 지우면 자동 저장된 문서와 저장 기록이 함께 사라지니, 필요한 문서는 먼저 문서 파일로 저장해 두세요.

### 자동 저장된 문서를 열지 못했다는 안내가 떠요

자동 저장 파일이 망가지는 등의 이유로 읽지 못하면, 지면은 편집 화면 위쪽에 안내 막대를 띄웁니다. 어떤 안내인지에 따라 다음과 같이 하면 됩니다.

- **'최근 저장본을 읽지 못해 이전 저장본을 열었습니다'**: 바로 전 저장본(`document.previous.json`)이 열린 것입니다. 마지막에 고친 내용이 조금 빠져 있을 수 있으니 확인해 보세요.
- **'자동 저장 문서를 읽지 못했습니다'**: 빈 문서로 시작한 것입니다. 안내 막대의 **가져오기**를 눌러 **문서 저장**으로 만들어 둔 `.jimyeon` 파일을 열면 됩니다. 문서 메뉴(**…**)의 **저장 기록**에 기록이 남아 있다면 거기서 되돌릴 수도 있습니다.

읽지 못한 파일은 지우지 않고 [자동 저장 폴더](#내-문서는-어디에-저장되나요)에 이름만 바꿔 남겨 둡니다. 안내에 나오는 '같은 폴더'가 바로 이 폴더입니다. 바뀐 이름은 `document.corrupt-1760000000000.json`처럼 끝에 긴 숫자가 붙습니다(이전 저장본은 `document.previous.corrupt-숫자.json`). 이 숫자는 날짜가 아니라 파일을 옮긴 시각을 1000분의 1초 단위로 센 값이라, 숫자가 클수록 나중에 옮긴 파일입니다.

다른 프로그램이 이 파일을 쓰고 있는 등의 이유로 옮기지 못하면, 원래 파일을 덮어쓰지 않도록 자동 저장이 멈추고 맨 위에 '저장 실패'가 보입니다. 그동안 쓴 내용은 **문서 저장**으로 파일에 저장해 두세요. 그 프로그램을 닫은 뒤 글을 고치면, 다음 자동 저장 때 파일을 다시 옮기고 저장을 이어 갑니다.

### 리눅스나 ARM 칩 윈도우 PC에서도 쓸 수 있나요?

지금은 맥(Apple 칩·Intel 칩)과 64비트 윈도우(Intel·AMD 칩)용 파일만 만듭니다. 리눅스와 ARM 칩을 쓰는 윈도우 PC용 파일은 아직 없습니다.

### 인터넷이 꼭 있어야 하나요?

아니요. 설치한 뒤에는 인터넷 없이 문서를 쓰고 PDF로 저장할 수 있습니다. PDF 저장에 필요한 것도 앱 안에 들어 있어서, 크롬 같은 다른 프로그램을 따로 설치하지 않아도 됩니다. 웹 주소로 넣은 이미지·영상·오디오·임베드만 인터넷이 있어야 보입니다. 북마크는 누를 때 브라우저로 열리므로, 그때 인터넷이 필요합니다.

### 내려받은 파일이 진짜인지 확인하고 싶어요

최신 버전 페이지에는 `SHA256SUMS.txt` 파일도 있습니다. 여기에는 파일마다 고유한 '지문'(영문자와 숫자로 된 64자리 문자열)이 적혀 있습니다. 내가 받은 파일의 지문을 직접 계산해서 이 값과 같으면, 올린 파일이 중간에 바뀌지 않고 그대로 받아졌다는 뜻입니다.

받은 파일이 '다운로드' 폴더에 있다면, 맥은 **터미널**에 아래 명령을 붙여 넣습니다.

```bash
shasum -a 256 ~/Downloads/Jimyeon-*.dmg
```

윈도우는 시작 메뉴에서 **PowerShell**을 열고 아래 명령을 붙여 넣습니다.

```powershell
Get-FileHash $HOME\Downloads\Jimyeon-*-Setup.exe
```

`.zip` 파일을 받았다면 명령 끝을 `Jimyeon-*.zip`으로 바꿉니다. 화면에 나온 긴 문자열을 `SHA256SUMS.txt`에서 같은 파일 이름 옆에 있는 값과 비교하세요. 윈도우에서는 대문자로 나오는데, 대소문자는 달라도 괜찮습니다.

### 문제를 알리거나 의견을 보내고 싶어요

[이슈 페이지](https://github.com/vpdls1511/Jimyeon/issues)에 남겨 주세요. GitHub 계정이 필요합니다. 맥인지 윈도우인지, [지면 버전](#내-지면-버전은-어떻게-확인하나요), 무엇을 했고 어떻게 됐는지 적어 주시면 원인을 찾기 쉽습니다. 개인 문서 대신 같은 문제가 생기는 작은 문서를 붙여 주세요.

## 만든 이유

저는 노션이나 옵시디언, 워드, 슬랙 캔버스, 한글 등 여러 문서 작성 도구를 사용해 보았는데요. 사용하면서 매번 조금씩 아쉬웠던 부분이 있었습니다.

노션은 편하지만 폰트 크기나 여백 등을 자유롭게 조절하기 어려웠고, 실제 PDF로 출력했을 때 작성하면서 생각했던 모습과 달라지는 경우도 있었습니다. 옵시디언은 자유롭지만 제가 선호하는 블록 형태로 문서를 작성하기에는 조금 불편했고요. 그렇다고 워드나 한글을 사용하자니 익숙하면서도 노션에서 느꼈던 편리한 작성 경험이 아쉽기도 했습니다.

그래서 실제로 문서를 작성하며 겪었던 문제를 직접 해소해보고자, 코덱스를 회초리질하며 데스크톱 앱을 하나 만들어보았습니다. 이름은 '지면'입니다.

블록 기반으로 편하게 문서를 작성하면서도 A4, A3 같은 실제 용지를 기준으로 편집하고, 작성한 모습을 최대한 그대로 PDF로 출력할 수 있는 에디터를 목표로 만들고 있습니다.
